
# CCNA Networking Labs

## About This Repository

This repository documents my CCNA networking
learning journey through practical exercises,
network configuration, troubleshooting, and
technical documentation.

The goal is to develop a strong understanding
of computer networking fundamentals and
hands-on networking skills.

## Learning Objectives

- Understand OSI and TCP/IP Models
- Learn Ethernet and MAC Addressing
- Practice IPv4 and IPv6 Addressing
- Understand Subnetting
- Study ARP, DHCP, and DNS
- Learn Switching and VLANs
- Understand Routing Concepts
- Perform Basic Network Troubleshooting

## Tools and Technologies

- Cisco Packet Tracer
- Wireshark
- Windows Command Prompt
- Linux Terminal
- Git and GitHub
